====================================================================
COMMAND MENYIAPKAN PYTHON & MENJALANKAN BOT DARI AWAL DI PM2
====================================================================

File ini dibuat agar bisa langsung di-copy paste step-by-step
dari setup Python environment sampai bot running 24/7 di PM2.


====================================================================
OPSI A: UNTUK SERVER LINUX / VPS (UBUNTU / DEBIAN)
====================================================================

# STEP 1: Masuk ke folder bot
cd ~/AITrbot-Playground
# (atau arahkan ke folder tempat bot diekstrak)

# STEP 2: Siapkan Virtual Environment Python
python3 -m venv venv

# STEP 3: Aktifkan Virtual Environment
source venv/bin/activate

# STEP 4: Upgrade pip & Install seluruh dependencies
pip install --upgrade pip
pip install -r requirements.txt

# STEP 5: Pastikan file .env sudah ada (isi API KEY & Webhook)
# Jika belum ada:
# cp .env.example .env
# nano .env

# STEP 6: Jalankan Bot dari awal di PM2 menggunakan Python venv
pm2 start main.py --name "ai-trade-bot" --interpreter ./venv/bin/python3

# STEP 7: Simpan list PM2 agar otomatis jalan saat server reboot
pm2 save
pm2 startup


# ------------------------------------------------------------------
# JIKA ADA PERUBAHAN BARU / UPDATE KODE DI SERVER LINUX / VPS:
# ------------------------------------------------------------------

====================================================================
COMMAND PENTING PM2 LAINNYA (BISA DI-COPY KAPAN SAJA)
====================================================================

# Melihat status bot (apakah online/error/memory):

# Melihat log terminal bot secara live real-time:

# Restart bot:

# Stop bot sementara:

# Hapus bot dari list PM2 (jika ingin reset ulang dari awal):
